AZ SMART BUSINESS - STARTER PWA

This is a first working prototype of an installable web app (PWA).

Included:
- Service cards for mould, die, EDM, machining and engineering
- Customer enquiry form
- Form opens WhatsApp with the enquiry pre-filled
- Contact details for AZ Mould & Engineering Solutions
- PWA manifest and service worker for install/offline shell

IMPORTANT:
1. This is not yet published online.
2. To install as an app, it must be hosted on an HTTPS website.
3. A free hosting option is GitHub Pages. It requires a GitHub account and setup.
4. This does not publish the app to Google Play Store.
5. The enquiry form sends details to WhatsApp; it does not store enquiries in a database.
6. Before public launch, verify all phone/email/business details and add a privacy policy.

Next step:
Create/sign in to a GitHub account, create a public repository named az-smart-business,
upload all files from this folder to the repository root, then enable GitHub Pages
from Settings > Pages > Deploy from a branch > main > / (root).
